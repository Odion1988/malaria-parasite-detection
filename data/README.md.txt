# Dataset Information

This project uses a microscopic blood smear image dataset for malaria parasite detection.

The dataset is used to train, validate, and evaluate the deep learning models developed in this research project.

## Dataset Usage

The images are processed and used for binary classification of malaria-infected and uninfected blood smear samples.

## Repository Policy

The complete dataset is not stored in this GitHub repository.

This is to avoid uploading large image files directly into the repository and to keep the project repository focused on source code, documentation, and reproducible development artefacts.

## Data Preparation

The dataset used in the project should be placed in the appropriate local working directory before running the notebook.

The preprocessing and model-development workflow is contained in:

`notebooks/malaria_detection_project.ipynb`

## Reproducibility

The notebook contains the preprocessing, model training, evaluation, and ensemble-learning workflow used for the project.
