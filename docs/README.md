# Supporting Project Documentation

This folder contains supporting documentation already produced for the malaria parasite detection research project.

## Included artefact

- `SYSTEM USABILITY AND FUNCTIONALITY EVALUATION QUESTIONNAIRE.docx` — the existing system usability and functionality evaluation questionnaire from the project materials.

The questionnaire is included as supporting evidence for the project's system evaluation activities.

## Scope

The full dissertation report is not duplicated in this folder. The repository is focused on source code, reproducibility information, result artefacts, dataset documentation, and supporting development/evaluation documentation.

No academic content in the included questionnaire has been rewritten or altered for this repository.
